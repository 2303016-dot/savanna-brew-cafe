Savanna Brew Cafe - HTML and CSS Assignment
===========================================

Pages: index.html, about.html, menu.html, gallery.html, contact.html
Stylesheet: css/style.css (one external file, no inline styles, no <style> tags)

How to view: open index.html in a browser from the unzipped folder.

Validation
----------
I checked the HTML pages with the W3C Markup Validator and css/style.css
with the W3C CSS Validator.

Notes
-----
- Images in the images folder are placeholders (solid colour with a label).
  They can be replaced with real photos using the same file names.
- Fonts (Playfair Display and Open Sans) are loaded from Google Fonts,
  with Georgia and Arial as fallbacks.
- Bonus features: fade-in animation on the hero text and a dark mode
  using prefers-color-scheme.

Extra page
----------
offers.html (Offer Deals) lists coffee and food packages in three tables
and is linked from the navigation and from the home page.
